# Storybook Trinkets

A growing collection of small illustrations in a fairy-tale hand-drawn style.
Each trinket is one little object, drawn like it fell out of a picture book.

童话手绘风小物件收藏：每一件都是一个小东西，画得像从童话书里掉出来的。

## Style guide

- Hand-drawn, storybook feel: soft watercolor textures, gentle outlines.
- One object per piece, centered, no background clutter.
- Square-ish framing so pieces sit nicely together in a gallery.

## Adding a new trinket

1. Add the illustration under `trinkets/` as `<name>.webp`.
2. Add a row to the table above.
